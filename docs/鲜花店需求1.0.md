# 鲜花店店铺管理需求 1.0

## 1. 项目背景
在 MeshCentral 管理系统中集成鲜花店店铺管理功能，旨在提供一个直观、易用的店铺信息维护界面。

## 2. 界面设计要求
- **风格参考**：美团 H5 移动端页面风格。
- **视觉特点**：
  - 采用卡片式布局展现店铺列表。
  - 使用美团标志性的黄色 (#FFD000) 作为主色调。
  - 响应式设计，适配桌面端和移动端（MeshCentral 内部嵌入）。
  - 图标使用简洁明快的风格。

## 3. 功能需求
### 3.1 店铺列表 (Read)
- 展示所有已登记的鲜花店。
- 每项卡片展示：店铺预览图、店铺名称、评分（星星）、地址、联系电话、营业时间、距离（模拟）。
- 支持按名称模糊搜索。
- 支持点击进入详情查看（可选）。

### 3.2 添加店铺 (Create)
- 提供“新增店铺”悬浮按钮或顶部按钮。
- 输入项：店铺名称、封面图 (URL/生成)、联系电话、详细地址、营业时间、主营分类。
- 提交校验：名称和电话必填。

### 3.3 编辑店铺 (Update)
- 列表项支持“编辑”操作。
- 弹出美团风格的半屏或全屏表单进行修改。

### 3.4 删除店铺 (Delete)
- 支持滑动删除或点击删除图标。
- 弹出符合美团视觉风格的确认弹窗。

## 4. 导航集成
- **左侧导航栏**：在 `LeftMenuMyServer` (My Server) 之后或适当位置增加一个“店铺管理”图标。
- **图标 ID**：`LeftMenuShopManager`。
- **路由逻辑**：点击图标调用 `go(X)` 函数（需定义新的页面 ID），在主区域显示店铺管理视图。

## 5. 交互与动效
- 列表加载时的骨架屏效果。
- 按钮点击时的涟漪效果或缩放反馈。
- 页面切换时的平滑过渡。

## 6. 技术实现思路
- **HTML/Handlebars**：在 `default.handlebars` 的 `page_leftbar` 添加按钮，在 `column_l` 添加对应的页面容器 `div id=p20`。
- **CSS**：在 `styles/style.css` 或新增 CSS 块中定义 `.meituan-card`, `.meituan-btn` 等样式。
- **JavaScript**：在 `scripts/meshcentral.js` 或自定义脚本中添加 `onShopManager()` 相关逻辑，处理 CRUD 数据流。

## 7. 待确认问题 (需求问题)
1.  **数据持久化**：目前是仅在前端演示（LocalStorage）还是需要对接 MeshCentral 的后端数据库（db.js）？
2.  **图片处理**：店铺 Logo 是否需要实现真正的文件上传功能，还是先用 URL 或 AI 生成占位图？
3.  **权限控制**：哪些级别的用户可以看到并操作“店铺管理”？（如：仅管理员可见，还是所有用户可见自己的店铺）
4.  **图标位置**：左侧导航栏图标的具体顺序，以及是否需要为移动端 `default-mobile.handlebars` 也做适配？
5.  **字段扩展**：除了基础信息，是否需要添加“库存管理”、“订单统计”等后续功能的入口占位？
