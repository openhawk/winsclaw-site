# 鲜花店店铺管理需求 1.0

## 1. 项目背景
在 MeshCentral 管理系统中集成鲜花店店铺管理功能，旨在提供一个直观、易用的店铺信息维护界面。

## 2. 界面设计要求
- **风格参考**：美团 H5 页面风格，适配桌面端管理系统的实际使用场景。
- **视觉特点**：
  - 采用卡片式布局展现店铺列表。
  - 使用美团标志性的黄色 (#FFD000) 作为主色调点缀，整体保持与 MeshCentral 管理后台相协调的克制风格。
  - 响应式设计，优先适配桌面端浏览器，兼顾移动端。
  - 图标使用简洁明快的风格。

## 3. 功能需求

### 3.1 店铺列表 (Read)
- 展示所有已登记的鲜花店。
- 每项卡片展示：店铺封面图、店铺名称、主营分类、所在城市/区域、联系电话、营业时间。
- 支持按名称模糊搜索。
- 店铺数量较多时支持分页展示（每页默认 10 条）。
- 列表为空时展示友好的空状态提示（如"暂无店铺，点击右上角添加"）。
- 支持点击卡片进入详情查看（可选，1.0 版本可折叠在编辑弹窗中实现）。

### 3.2 添加店铺 (Create)
- 提供"新增店铺"按钮（页面右上角）。
- 输入项：店铺名称、封面图（URL 填写）、联系电话、详细地址、所在城市/区域、营业时间、主营分类。
- 提交校验：名称和电话必填，其余选填。
- 提交成功/失败后展示 Toast 轻提示。

### 3.3 编辑店铺 (Update)
- 列表卡片操作区提供"编辑"按钮，点击后弹出全屏或居中弹窗表单进行修改。
- 编辑弹窗复用新增表单，字段预填入当前店铺数据。
- 保存成功/失败后展示 Toast 轻提示。

### 3.4 删除店铺 (Delete)
- 列表卡片操作区提供"删除"按钮（与编辑按钮并列）。
- 点击删除后弹出确认弹窗，防止误操作。
- 确认删除后列表自动刷新，并展示 Toast 轻提示。

## 4. 导航集成
- **左侧导航栏**：在 `LeftMenuMyServer`（My Server）之后增加"店铺管理"图标按钮。
- **图标 ID**：`LeftMenuShopManager`。
- **路由逻辑**：点击图标调用 `go(100)` 函数（使用 `p100` 作为页面 ID，避免与现有 `p10~p99` 冲突），在主区域显示店铺管理视图。
- **顶部菜单栏**：同步在 `MainMenuSpan` 中添加对应的顶部菜单项 `MainMenuShopManager`，保持两套导航一致。

## 5. 交互与反馈
- 页面切换时使用**淡入（fade-in）过渡**，保持与 MeshCentral 整体风格协调，不使用涟漪等移动端专属动效。
- 所有增删改操作完成后展示**顶部 Toast 轻提示**（成功/失败不同样式）。
- 空状态、加载中等需要有明确的视觉反馈。

## 6. 技术实现思路
- **HTML/Handlebars**：在 `default.handlebars` 的 `page_leftbar` 添加按钮；在 `column_l` 添加对应的页面容器 `div id=p100`，避免与现有页面 ID 冲突。
- **CSS**：在 `styles/style.css` 中追加，或新建独立 CSS 文件，定义 `.shop-card`、`.shop-btn`、`.shop-toast`、`.shop-empty` 等样式类，前缀统一用 `shop-` 避免与现有样式冲突。
- **JavaScript**：在 `scripts/meshcentral.js` 或自定义脚本中添加 `shopManager` 相关逻辑，处理 CRUD 数据流。
